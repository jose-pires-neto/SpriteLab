# Documentation media

- `spritelab-cover.png`: AI-assisted promotional illustration generated with OpenAI imagegen, using the original slime as style/character reference. It is not a screenshot or engine output.
- `editor-slime-0.5.0.png`: actual native SpriteLab 0.5.0 window capture with the original editable slime at 600% zoom. Only app content is shown.
- `editor-slime-demo.mp4`: actual ScreenCaptureKit window recording of SpriteLab 0.5.0 playing that document, 1280×860, approximately eight seconds, no audio. The GIF is derived from that recording for README playback.
- `slime-menta.gif`: benchmark animation exported by SpriteLab; MP4 is a nearest-neighbor display conversion of the export. This is not an editor recording.

Original mascot/project: 64×64, three layers, 32 frames, 2.1-second loop. The editable example in `examples/slime-menta` preserves it. Promotional artwork and original example use the repository MIT license. No Aseprite/Photoshop artwork/fonts/icons were copied.
