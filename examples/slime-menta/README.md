# Slime Menta

Original SpriteLab benchmark: 64×64, three layers, 32 frames, 2.1 seconds per loop. The original procedural detached pixel buffers were committed through MCP/Command Engine, then saved/exported by SpriteLab. This is an editable project, not an imported finished GIF.

Copy `Slime-Menta.spritelab` into your workspace and open it from Arquivo. CLI/MCP can call `document.open` with a new document ID and the workspace-relative path. Inspect layer/frame IDs before editing; save copies rather than replacing the sample. The spritesheet is canonical output; PNG and JSON describe the same row-major frame sequence.

Original example asset is available under the repository MIT license. The promotional cover is separate AI-assisted artwork inspired by this sprite and must not be confused with engine-rendered benchmark output. Documentation video distinguishes actual desktop capture from the animation export.
